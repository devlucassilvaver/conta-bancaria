# 💳 Conta Bancária

Projeto desenvolvido em Java com foco em Programação Orientada a Objetos (POO), simulando operações básicas de uma conta bancária.
O sistema permite criar contas, realizar depósitos, saques e consultar saldo, aplicando conceitos fundamentais de modelagem de classes, encapsulamento e boas práticas.

---

## 🚀 Funcionalidades

* Criar uma conta bancária
* Depositar valores
* Sacar valores com validação de saldo
* Consultar saldo atual
* Exibir dados da conta
* Alterar dados da conta

## ▶️ Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/conta-bancaria.git
```

2. Acesse a pasta do projeto:

```bash
cd conta-bancaria
```

3. Compile o projeto:

```bash
javac Main.java
```

4. Execute o programa:

```bash
java Main
```
